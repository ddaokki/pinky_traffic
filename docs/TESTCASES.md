## B. 현장 테스트케이스 (19개, 자동 판정)


주행하는 동안 대시보드 서버가 로봇의 상태·이벤트를 보고 통과/실패를 **자동으로** 찍는다 (`dashboard/autocheck.py`).
결과는 대시보드 아래쪽 표와 `runs/날짜/testcase_results.json` 에 남는다. 한 번 통과한 항목은 그대로 두고, 실패한 항목은 다음 시도에서 통과하면 바뀐다.
자동 판정이 틀렸을 때는 표의 버튼으로 직접 고칠 수 있다.


### 0. 준비

| ID | 항목 | 하는 것 | 자동 통과 기준 |
|---|---|---|---|
| S-01 | 배터리 7.2V 이상 | 주행 노드가 /battery/voltage 를 받는다 | 두 로봇 모두 7.2V 이상 (자동, 7.0V 아래면 실패) |
| S-02 | 카메라 영상 수신 | 대시보드에 두 로봇 영상이 뜬다 | 두 로봇 모두 fps 8 이상 (자동) |
| S-03 | 비상정지 | 달리는 중에 비상정지(스페이스바) | estop 상태가 되고 속도 0 (자동) |

### 1. 인식

| ID | 항목 | 하는 것 | 자동 통과 기준 |
|---|---|---|---|
| P-01 | 직선에서 양쪽 차선 | 직선 구간을 달린다 | 양쪽 선이 다 보이고 차선 중심 ±0.1 안으로 3초 (자동) |
| P-02 | 파란 표지판 인식 | 표지판 앞으로 달린다 | 표지판을 보고 다가가기 시작 (자동) |
| P-03 | 초록 선 인식 | 2차선 로봇이 칸에 들어간다 | 초록 선을 보고 그 위까지 감 (자동) |
| P-04 | 지나가는 상대 로봇 인식 | 칸 안에서 상대가 입구 앞을 지나간다 | 카메라/라이다로 상대를 봤다가 사라진 것을 확인하고 나옴 (자동) |

### 2. 1차선 로봇

| ID | 항목 | 하는 것 | 자동 통과 기준 |
|---|---|---|---|
| L1-01 | 첫 표지판에서 깃발 | 1차선 로봇이 우회전 표지판을 본다 | oncoming 깃발이 올라감 (자동) |
| L1-02 | 표지판 경로 우→우→직진 | 1차선 로봇이 갈림길을 지난다 | 경로 완주 (자동, 표지판을 못 찾고 경로를 버리면 실패) |
| L1-03 | 경로 뒤 흰 차선 복귀 | 경로를 마친 뒤 계속 달린다 | 5초 동안 lost 없이 차선 주행 (자동) |

### 3. 2차선 로봇

| ID | 항목 | 하는 것 | 자동 통과 기준 |
|---|---|---|---|
| L2-01 | 상대가 오면 칸으로 비킴 | 1차선 로봇과 같이 출발 | 직우 표지판에서 깃발을 보고 칸으로 우회전 (자동) |
| L2-02 | 초록 선 위 180도 후 대기 | 칸에 들어간다 | 초록 선 위에서 돌고 대기 상태 (자동, 초록을 못 찾고 포기하면 실패) |
| L2-03 | 상대가 지나가면 탈출 | 상대가 칸 앞을 지나간다 | 칸에서 나옴 (자동) |
| L2-04 | 탈출 뒤 우→좌→좌로 1차선 | 칸에서 나온다 | 탈출 경로 완주 (자동, 경로를 버리면 실패) |
| L2-05 | 상대가 없을 때 직진→좌→좌 | 2차선 로봇 혼자 달린다 | 칸에 안 들르고 경로 완주 (자동) |
